# Visual system

Original editorial portfolio, informed by the AIR audits rather than copied imagery or type. 20px desktop and 10px mobile page edges; thin rules organize split layouts, directories, and chronology. Semantic opaque surfaces are charcoal `--surface: #171d25`, slate `--surface-raised: #222d39`, and deep charcoal `--surface-deep: #111820`; `--text: #edf4f7` carries copy, `--accent: #82c9df` is used sparingly for cyan highlights, and `--line` provides subtle light rules. The home hero contains original Three.js toroidal fiber linework with slowly varying icy-blue fiber illumination; its deterministic server-rendered SVG fallback traces a static toroidal wire ring rather than crossed ellipses. Project SVG marks remain original abstract symbols.

Typography uses self-hosted Hanken Grotesk variable roman (`wght`), declared 300–700 with `font-display: swap` and Arial fallback; editorial headings and ordinary copy default to weight 300. Only the home hero heading uses a bold system-first stack (`-apple-system`, `BlinkMacSystemFont`, `Segoe UI`, Arial); no Apple font files are bundled. The file `public/fonts/licensed/HankenGrotesk-wght.ttf` and its accompanying `OFL.txt` were fetched from Google Fonts' `ofl/hankengrotesk` directory. The repository's `METADATA.pb` identifies Hanken Grotesk, designer Alfredo Marco Pradil / Hanken Design Co., OFL licensing and a 100–900 weight axis; `OFL.txt` credits the Hanken Grotesk Project Authors and states SIL Open Font License 1.1. SHA-256 font: `813b3f8fa0965405669a89b38e51bbefd95eef6b8e20d1cb2d8c10cce062662f`; license: `e02ccb89a86839b22feff7872ff5cc355cc0f58318d29eee20e2cf83a612f16d`. Existing bundled Helvetica files remain unused because their license has not been verified. No default Geist or runtime Google Fonts fetch.

Compared with the existing AIR audit, measured AIR page-title and body weights are 300, which the inner-page weight choice matches nominally; AIR's declared family is Akzidenz-Grotesk, **not** Hanken Grotesk, so glyph widths and shapes remain different. AIR measured page titles are 30px desktop / 24px mobile; this portfolio retains larger identity-led display headings as an intentional composition difference because an AIR homepage hero heading size was not measurable. The original boxed ornament has been replaced by a hero-only unboxed torus behind the title. Actual rendered widths and wrap at 360/390 still require a real browser viewport check. Smaller metadata is 14px; body copy remains 16–18px. All factual project/career content is migrated, not extrapolated.

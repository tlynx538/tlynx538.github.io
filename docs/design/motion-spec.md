# Motion specification

Page navigation and outbound links, including the published Dropbox résumé, open in new tabs with `target="_blank"` and `rel="noopener noreferrer"`. The skip-to-content and back-to-top anchors remain within the current page. Opening another tab loads that destination directly; the torus travel animation remains available for same-tab history or navigation. No navigation blocking or manual transition timers are introduced.

On inner-page initial load and when an inner page's `<main>` mounts after an App Router route change, CSS runs a single 280ms ease-out from 97% opacity and +6px vertical offset to its normal position. Content is never fully hidden; there is **no exit transition** or delayed navigation. A link hovered in the project directory moves 3px over 200ms, and ordinary links gain a thin underline; keyboard focus retains its high-contrast outline. The hero torus is a decorative Three.js line-segment mesh loaded after it enters the viewport; it rotates slowly, eases toward pointer position and pauses the render loop when offscreen. Per-fiber cool color intensities drift at a capped ~18 updates/second by mutating the existing GPU color buffer (no per-frame arrays), with no flashing or discrete random jumps. Pixel ratio is capped at 1.75; renderer and GPU geometry/materials are disposed on unmount. Static toroidal SVG remains visible before hydration and if WebGL fails, the context is lost, or reduced motion is enabled. Under `prefers-reduced-motion: reduce`, CSS forces the fallback visible and the canvas hidden even if the JS media-change listener has not run; the render loop checks the preference and stops, main animation is disabled, and scrolling is immediate. When the listener runs on re-enable, it renders once before showing the WebGL canvas. The mobile menu retains its `aria-expanded` toggle and closes on link activation.

The homepage has one torus in the hero and an empty corner slot. A persistent layout-level canvas travels to the 56px corner slot on inner routes, and returns to the hero when navigating home. The 1050ms Web Animations transform follows a gently damped spring with a small arc; rapid navigation samples the current visual position before reversing. Navigation is immediate. The canvas stays mounted and keeps its rotation, with layout-sized rendering preserving sharpness after a direct inner-page load. The hero destination fits a square within both stage dimensions with 16px clearance, keeping the rotating torus above the bottom divider and inside the horizontal bounds. The torus lives in document coordinates and scrolls natively with its anchor; scroll events never restart the route spring. Viewport and stage-size changes update the measured destination. The homepage disables the main arrival transform so hero text can remain above the traveling torus. Reduced motion places it immediately and retains the static SVG fallback.

On fine-pointer desktop devices, a light-gray (#d9d9d9) 18px circle replaces the native cursor after the first mouse movement. Hovering text, controls, images and content rows expands it to 36px over 180ms and uses a white fill with difference blending to invert the actual pixels beneath it. Hero headings, introductory copy and metadata also respond to hover. Pointer position updates once per animation frame without trailing; scrolling refreshes hover detection. The cursor never intercepts clicks, hides on window exit or keyboard Tab, and restores the native cursor for touch, reduced motion and unavailable JavaScript.
